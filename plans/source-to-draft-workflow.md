# 麦满分：从来源到推特草稿

> 2026-09-27 更新：已增加基于已登录浏览器的本机采集器，6 个用户样例完成真实正文／口播到资源库验收。以下表格描述早期公开网页入口；最新实测能力、启动方式与边界见 [采集验收记录](./source-ingestion-verification.md)。

## 产品边界

- 来源素材：别人发布的文章、帖子、视频字幕或分享文字，保留原链接和采集完整度，不直接当作我的观点。
- 灵感随笔：我自己的判断、疑问、体验；按时间记录，不自动混入外部原文。
- 成熟资源：人工挑选后可复用的钩子、案例、佐证等，必须能回到来源。
- 草稿：我的原创表达；来源摘录留在旁边供核对，不自动拼贴进正文。

## 当前已实现

`/write` 把采集、查阅和写作放在一屏：左侧来源素材，右侧推特草稿；手机端切换两栏。支持链接识别、公开页面尝试读取、直接粘贴全文/字幕、同链接更新、完整度标识、原文候选摘录、摘录入草稿、人工沉淀资源、草稿自动保存和复制。公开链接读取有超时、大小限制与域名白名单；读取失败可以继续手动粘贴。

| 来源 | 当前读取方式 | 不能承诺的事 | 稳定后续路径 |
| --- | --- | --- | --- |
| X | 公开页面标题/简介；本人原创已有独立 X 只读同步 | 公开网页不保证长帖全文或完整串帖 | 在管理员登录恢复后接官方按 ID 查帖，显式提示可能产生 API 费用；串帖逐条归并 |
| 小红书 | 公开页标题/简介 + 分享文字粘贴 | 电商开放平台不等于任意笔记全文接口 | 用户分享文字/复制全文为主；再评估经授权的合规接口 |
| 抖音 | 公开页标题/简介 + 字幕/口播粘贴 | 视频链接不等于可用的完整字幕 | 增加用户上传视频/音频后的语音转写，逐段校对时间戳 |
| 公众号 | 对公开 `mp.weixin.qq.com` 正文尝试抽取 | 登录墙、删文、折叠内容、图片中的字可能无法读到 | 公开正文抽取 + 用户补贴全文；本人公众号可另走官方授权 |
| 微博 | 公开页标题/简介 + 分享文字粘贴 | 网页抓取不保证全文 | 管理员登录恢复后接现有微博 CLI 授权读取，按接口价格和频率限制调用 |
| 普通文章 | 用户粘贴正文并保留 URL | 不开放任意网址的服务器抓取，避免内网访问风险 | 按实际需求增加可信站点适配器 |

官方依据：[X Post Lookup](https://docs.x.com/x-api/posts/lookup/introduction)、[抖音授权视频接口](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/account-video-list)、[小红书开放平台](https://open.xiaohongshu.com/)、[微博 CLI](https://open.weibo.com/cli/quickstart)。

## 下一阶段验收标准

1. 重新启用管理员登录与 Supabase 行级权限；将来源、草稿及摘录从本机存储迁到专属数据库，手机与电脑实时可见。迁移必须先做导出、去重和回滚验证。
2. 用户提交 4 个核心平台各 3 条真实链接（短帖、长帖、视频各类），逐条记录“全文、片段、仅简介、失败”而非只报成功率；失败必须提供一步粘贴补全入口。
3. 付费接口只在管理员明确触发时调用，记录平台、接口、次数和估算费用；严禁公开暴露 X/微博令牌。
4. 视频上传转写必须显示时间戳和置信度，用户校对后才能成为可引用文本；不得从封面或标题臆造口播。
5. 引用事实必须保留原句、URL、采集时间和复核状态。AI 可以建议候选，不能把“来源声称”标成“事实已核实”。
6. 草稿复制到 X/微博前由用户确认；外部素材不直接洗稿，不复制他人独有表达。

当前开发版素材存在浏览器 IndexedDB，草稿存在浏览器本地存储，尚未多端同步，也不是唯一备份。上线长期使用前应先完成第 1 项。
