# 本机 Codex 工作台（方式 B）

本轮交付：独立灵感/资源页面；本机 Codex 对话；可编辑创作档案；多份文本/PDF 上传；分段分析、出处校验、人工确认入库；持久任务和失败重试。

边界：只在 loopback 3002 开放；沿用本机 Codex 登录，不复制凭据；不继承其他聊天；不代替用户发布；不修改旧 Obsidian。文件解析在本机，选中的文本发送给 Codex 服务进行分析，占用现有账号额度。网页关闭不取消任务，电脑必须开机。暂不提供公网/手机远程桥接。

来源与摘要分离，原始文档不可被模型改写。知识块附来源、页码/段落、原文摘录和待核验标记。AI 只返回结构化建议，不运行材料内的命令。确认是入库的唯一入口。

验证：安全边界、来源定位、去重、持久化/恢复、失败与畸形输出、真实 Codex 调用、构建和页面交互。

下一阶段（不绑定 Obsidian）：写作时按问题检索已确认知识块，显示支持/反例/来源，记录引用与使用次数，优先回顾与当前选题有关的旧知识。以被引用的次数而不是收藏数量衡量价值。
