## 选择的实现

- 文章／帖子优先使用 OpenCLI 已登录浏览器适配器；网页登录不等于每个平台都永远可用。
- 视频下载到本机，faster-whisper small CPU int8 识别；真实语音时间戳交给 DeepSeek 做语义分段，不机械三等分。
- GitHub 单独读取官方仓库元信息，记录用途、许可和来源文章；没有执行第三方仓库代码。
- 原文先落盘，再调用 AI。AI 失败保留原文；重复已完成来源不再次调用模型。
- 引文逐字对齐来源；数字、收益与案例均标记为来源陈述，未独立核实。
- 资源库与灵感随笔分开。资源可带入 `/write`，左侧核对来源，右侧写原创；手机布局保留两栏切换。

工具依据：[OpenCLI](https://github.com/jackwener/opencli)、[faster-whisper](https://github.com/SYSTRAN/faster-whisper)。抖音浏览器导航异常参考 [上游问题](https://github.com/jackwener/opencli/issues/2533) 与 [有界重试修复](https://github.com/jackwener/opencli/pull/2512)，增加一次重试，并为视频下载提供来源页请求头。

## 本机使用

1. 保持已登录的 Chrome 与 OpenCLI 扩展连接。
2. 项目构建后运行 `npm run sources:start`。仅监听 `127.0.0.1:3002`，不向局域网或公网开放浏览器采集能力。
3. 打开 `http://127.0.0.1:3002/inspire` → 资源库，粘贴分享链接 → 采集并整理。
4. 原始数据位于 `C:\Users\Administrator\.agent-reach\zmt-import\library`；浏览器只是展示与编辑副本。
5. `npm run sources:export` 导出资源包到该目录上一级的 `resource-library.json`。不包含登录 Cookie、AI 密钥或 X/微博 API 凭据。
6. 浏览器配置映射保存在本机 `collector-config.json`，不进入代码仓库；登录状态变更后可调整 profile。环境变量 `ZMT_OPENCLI_PROFILE_<PLATFORM>` 可覆盖。

## 尚未完成、不能夸大的部分

- 本次是这 6 个真实样例通过，不代表所有帖子／历史串帖／图文／付费文章都经过覆盖测试。X 普通短帖和多帖 thread 需继续扩展专项验收。
- 文章图片中的字没有 OCR；视频当前识别口播，没有逐镜头视觉拉片。不能把“主体文字取得”说成所有嵌入图表都已理解。
- 验证码、登录失效、内容删除会中断读取，应明确提示用户完成正常验证，不能绕过平台访问控制。
- 本机采集必须电脑在线。尚未部署云端采集队列、跨设备自动同步；公网网页不能直接调用用户 Chrome 登录态。
- 当前站点暂时关闭登录，因此不能把个人素材和已登录浏览器能力直接暴露给公网。多端自动同步应在恢复管理员访问保护之后再接 Supabase。
- 只读取和整理资料，没有自动发布、自动转发或新增平台充值。AI 总结使用已有 DeepSeek 配置，按实际模型调用计费。
