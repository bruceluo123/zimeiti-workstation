## 仍未接通

- X 官方 API：尚未提供/核验应用权限和令牌，故**没有**自动抓取、定时任务、历史起点、媒体与编辑链同步。当前手动导入内容也未自动核对 X 原帖。
- 微博官方发布：尚未核验该账号的 CLI/开发者服务资格，故没有“点一次即直接发布”；人工交接需用户自己在微博完成发帖。
- 抖音、视频号、小红书：未授权，暂无直接发布或数据回流。
- 视频上传、视频拆解、自动初剪、剪映交接：尚未实现；目前只有原创转拍摄稿和口播提词。
- 旧 Upstash 云端内容仍待核对、导入；旧凭据应在受影响的其他系统确认后轮换。
- 尚未进行生产部署。正式部署需要设置 Supabase、管理员邮箱与站点 HTTPS 地址，并在 Supabase Auth 的允许回跳列表加入生产域名；本地回跳已配置为 `http://localhost:3002/auth/callback`。

## 运行入口

配置 `.env.local` 的 `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`、`ZMT_OWNER_EMAIL`、`ZMT_SITE_URL`。专用数据库按 `supabase/migrations/` 顺序迁移。`npm run dev` 后打开 `/login`；登录后 `/content` 处理原文和微博草稿，`/legacy` 备份此设备旧内容。

不要把真实社交平台 token、原片、旧 KV 导出、完整知识库或 `.env.local` 放进公开仓库。
