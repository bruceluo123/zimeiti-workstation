# AI 工作台：本机 Codex（方式 B）

入口：`http://127.0.0.1:3002/assistant`。运行 `npm run build` 后，用 `npm run sources:start` 启动本机服务。监听地址仅为 127.0.0.1，不公开 Codex 端口。

## 现在能做什么

- 使用官方 Codex App Server stdio 协议，复用本机 ChatGPT 登录。模型列表来自已登录 Codex；本机验收默认为 GPT-5.6 Sol，不需要添加 OpenAI API key，也不会回退至 DeepSeek。
- 保存独立的创作档案、会话历史、来源、任务进度和知识块。不自动导入其他 ChatGPT/Codex 聊天，也不遍历 Obsidian 或电脑文件。
- 导入 UTF-8 TXT/MD/SRT/VTT、带文字层 PDF；多文件逐个处理。单文件 20 MB，单来源 200 万字，单任务最多 10 份来源。PDF 解析依赖本机 Python + pypdf。
- 文字按 6000 字分块，每批最多 4 块交给 Codex。界面显示批次数；不静默丢弃长文尾部。普通对话最多附带 4 块，更长内容应先提炼入库。
- 原文摘录必须逐字匹配对应来源段；页码/段落由解析器产生，不接受模型自报的定位。提炼分观点、事实论据、案例、方法、工具资料、热点；候选块可编辑、拒绝或确认入库。入库不等于事实已核验。
- 来源资源库的现有文章/转写可点击“交给本机 Codex 提炼”，原有浏览器数据不迁移、不删除。
- AI 上下文包含创作档案、当前会话最近 12 条消息（每条最多 6000 字）、本次勾选资料、关键词命中的最多 6 个已确认知识块。不是全库无限上下文，也不是向量语义搜索。
- 知识块可搜索、查看原文、复制含出处；备份导出含来源文本。暂不支持备份文件自动恢复导入。

## 数据与恢复

默认保存：`%USERPROFILE%\.agent-reach\zmt-knowledge\state.json`，不放在网站公开目录，也不提交 Git。`state.backup.json` 是上一次有效写入的快照。可用 `ZMT_KNOWLEDGE_DATA_DIR` 指定独立目录。

后台任务由本机独立进程执行。关闭页面不取消任务，但关机/断网会中断；重启本机工作站会将中断任务标为失败，需手动重试。完成段落有检查点，重试从未完成段开始。最后一个未保存响应可能重新消耗额度；不承诺费用 exactly-once。

用户取消任务后保留已完成的候选块。每次只运行一个任务。文件损坏时拒绝覆盖，不自动重置数据库。数据是本机用户目录下的明文文件，请保护系统账号与备份。PDF 只保留解析后的分页文字，上传的临时 PDF 会删除，不宣称保存了原文件。

## 安全边界

- API 要求本机功能开关、固定 loopback Host、same-origin fetch metadata；写请求还要求同源 Origin。Vercel 禁止运行桥接。
- Codex 子进程沿用官方认证，不读取、复制或输出认证文件。过滤继承的服务密钥环境变量；状态仅返回可用模型与连接结果。
- 新建临时只读 Codex 会话，关闭 shell、浏览器、插件、MCP、hooks、多 agent、图像生成等能力。不执行资料中的指令。所有工具/审批回调拒绝。
- 原文/档案会通过已有 Codex 账号发送到模型服务；“本机连接”不代表本地离线推理。消耗该账号额度。
- 没有开放远程手机/公网访问。线上页面不能直接操作你电脑上的 Codex。以后需要单独的配对认证和加密通道，不应公开 3002 端口。

## 暂不支持

扫描 PDF OCR、直接理解上传视频、任意链接自动读取、自动导入全部旧笔记、自动发布到社交平台。视频可先用已有采集/转写流程取得字幕，再送入工作台。链接先经来源资源库采集，不能拿分享标题当完整视频分析。

## 让知识库活起来：已接入边查边写

入口 `/write` 已接入本机知识写作，操作与真实边界见 [知识参与写作](knowledge-writing.md)。支持自动关键词候选、Codex 判断论据/案例/反例、确认插入与撤销、使用记录及草稿反查；不是向量全库检索。

1. 以正在写的观点检索“支持论据 / 反例 / 相关案例”，将知识块放在编辑器左侧，右侧继续写作。
2. 插入知识块时附出处并记录它用于哪篇稿子，发布前重新核验时间敏感事实。
3. 从未使用但与当前选题相关的旧知识优先浮现；观点冲突并列展示，不让 AI 合并成看似一致的事实。
4. 指标看知识块被引用的次数、形成的稿件数和需要补证的缺口，而不是库存数量。不先堆更多分类。
