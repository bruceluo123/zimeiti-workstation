# 《高性价比人生指南》来源收录

本机运行 `node scripts/ingest-how-to-live-better.mjs --chapter 4` 可先检查第 4 节的 18 条；去掉 `--chapter 4` 后收录网页上的 33 节、608 条。导入脚本只读取固定的公开网址，并在网页结构或条目数量变化时停止。重复执行按每条建议的稳定锚点去重；已有条目内容发生变化时计入 `conflicts`，不会覆盖原有卡片或使用记录。

每条建议作为一张独立的“来源素材”卡，保留章节编号、书中概述、成本、收益、备注、原书所列文献及直达原文的链接。工作站的“资源库 → 来源资料 → 书籍”按章节查看；搜索会覆盖书籍和日常素材。从卡片进入“边查边写”会直接打开这条来源供核对。若要自动插入正文并记录使用，需先交给 Codex 提炼、人工确认成知识块，再从“知识推荐”插入。

导入过程不调用 AI，也不会把书中主张自动升级为已核验知识块。书中的 A/B/C 是作者评级；引用数字、医学、理财或法律相关建议时，应先核对原始文献和适用范围。个人素材库保存原文供检索，公开发布时只引用必要片段并标明出处，避免整书转载。
