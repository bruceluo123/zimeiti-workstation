# 知识参与写作（本机版）

入口：http://127.0.0.1:3002/write 。沿用已有本机工作站服务和 Codex 登录。

## 操作

1. 新建草稿，写标题或一段判断。也可先点击“备份并导入旧草稿”。原浏览器数据保留，新稿和知识块统一保存到本机知识库。
2. 左侧自动关键词召回已确认、可匹配原文的知识块。选中正文一段可限定上下文，也能单独输入检索要求。
3. “AI 找论据 / 案例 / 反例”才调用本机 Codex，按当前观点判断候选的用途和限制，并列出证据缺口。无匹配时不虚构论据；类别没有合适项可以为空。
4. “插入原文”保留引号与引用标记；“AI 融入预览”生成补充段落，用户可编辑、确认后插入光标处，不覆盖已有选区。原文与 AI 改写分别保存。
5. 引用可撤销。若已手改引用文字，移除只删引用标记，不自动删除改写。复制纯正文去掉标记；复制含出处保留出处。两者均不记录为发布。
6. 实际发布后，展开“记录实际发布”，粘贴链接确认。不会向任何平台发送内容。可撤销误记。
7. 资源库中的“用在哪些稿子？”显示当前使用、待复核、历史关联及标记发布的稿件，可回到对应草稿。

## 真实边界

- 自动检索是重叠中文词片段和英文词的关键词评分，不是向量语义搜索。最多召回 24 块，再由 Codex 判断关系；不会声称穷尽全库。
- 空检索框使用标题和正文末尾 5000 字，选中文字优先；输入检索要求则使用要求。长文建议逐段选中补证。
- Codex 沿用当前登录提供的默认可用模型。分析使用创作档案、当前上下文和候选，不读取其他聊天或文件，不联网，不发布。
- AI 的相关性判断、改写仍需人工核对，尤其是人名、数字和时效性。入库不等于独立核实。
- 知识写作仅支持本机，尚未远程同步手机；原始采集库仍保留既有存储，进入推荐须先提炼并确认。
- 分析/改写是当前页面请求，关闭页面或切换上下文会取消，不提供后台续跑；资料提炼仍使用既有后台任务。

## 数据保护与统计定义

- `state.json` 增加可选 `writing: { drafts, events }`，旧结构兼容。草稿修订号拒绝过期写入。
- 浏览器旧稿精确备份为 `zmt-writing-drafts-before-knowledge`；按内容指纹幂等导入，改过的旧稿再导入成为另一份，不覆盖本机稿。
- 未保存文字写临时恢复副本 `zmt-writing-recovery`。成功保存匹配内容后清除；下次打开可恢复为独立稿，不覆盖服务器新版本。浏览器存储被禁用时明确报错。
- `〔引N〕` 与原插入文字完整存在：active；标记还在但文字变化：modified（需复核，不计确定使用）；标记消失：removed。备忘单独计为 memo。
- 同一知识块在同一篇稿中的多次插入，只算一篇当前使用稿。插入、修改状态、移除事件留存；发布记录独立保存当时有效引用的 ID 快照，不因之后编辑而抹去。
- 发布链接只接受 HTTP(S)，不接受带登录凭据 URL。来源引用由服务器从已确认知识块与原文取得，不能由客户端伪造。
- 一秒防抖保存；未成功保存时正文保留、提示导出。两个窗口冲突不会静默覆盖。
